## Criterios de presentación

La evaluación se realizó por escrito. Las fotografías de las hojas se conservan en `EV-SUM-01/evidencias/`. `main.tex` contiene la transcripción de las respuestas manuscritas y `main.pdf` es el documento generado desde ese archivo LaTeX; las fotografías se mantienen separadas del PDF.

El archivo [README de EV-SUM-01](EV-SUM-01/README.md) explica el contenido de la actividad, la compilación reproducible y las indicaciones de entrega. El PDF de una página destinado al SGA es diferente de `main.pdf`, que corresponde a la digitalización de la prueba.
